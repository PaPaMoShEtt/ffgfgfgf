#Итоговая аттестация
## Random Quote Generator

## Автор: Урядов Владислав Романович
## Описание:
Генератор случайных цитат с графическим интерфейсом на Python. Позволяет генерировать случайные цитаты из базы, просматривать историю, фильтровать по автору и теме, добавлять новые цитаты с проверкой ввода. Данные сохраняются в JSON. Проект использует Git для контроля версий.

## Возможности:
- Генерация случайной цитаты.
- Отображение истории сгенерированных цитат.
- Фильтрация по автору и теме.
- Добавление новых цитат (с проверкой на пустые поля).
- Сохранение и загрузка данных (JSON).
- Использование Git.

## Инструкция по запуску:
1. Установите Python 3.x.
2. Установите зависимости: `pip install -r requirements.txt` (если требуется).
3. Запустите: `python main.py`

## Примеры использования:
- Нажмите «Сгенерировать цитату» — появится случайная цитата.
- Введите данные и нажмите «Добавить цитату» — новая цитата появится в базе.
- Используйте фильтры для поиска по автору или теме.

## Тесты:
- Проверьте генерацию при пустой базе (должно быть предупреждение).
- Попробуйте добавить цитату с пустыми полями (должна быть ошибка).
- Проверьте сохранение и загрузку истории.
